### 核心分层

| 层级         | 目录           | 职责                 |
| ------------ | -------------- | -------------------- |
| **入口**     | `main.rs`      | 配置加载、服务启动   |
| **路由**     | `lib.rs`       | 路由组装、中间件挂载 |
| **Handlers** | `handlers/`    | 请求处理、业务逻辑   |
| **Models**   | `models/`      | 数据查询、SQL 操作   |
| **中间件**   | `middlewares/` | 认证、权限校验       |
| **公共库**   | `chat-core/`   | JWT、通用模型、工具  |
